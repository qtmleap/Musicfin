# Musicfin UI 仕様

gpt-6-astra との設計相談で確定した決定事項。実装はこの仕様に従う。
設計の再検討はしない — 実装の対象はここに書かれた通りの画面。

## 1. タブ構成

**3 タブ**: ホーム / ライブラリ / 検索。

- 検索は `Tab(role: .search)` を使う
- 各タブは独立した遷移履歴を保持する
- ライブラリは「アルバム / アーティスト / プレイリスト / お気に入りの曲 / ジャンル」の
  一覧から詳細へ進む**入れ子構成**。segmented control と専用サイドバーは採用しない
- ジャンルは全アルバムのページ取得完了後に `genres` から集約する。
  取得途中の分類を全件として表示しない

## 2. ホームの縦構成

上から順に:

| セクション | 形式 | 寸法 |
|---|---|---|
| 最近追加したアルバム | 横カルーセル | アートワーク 180×180 pt |
| よく聴くアルバム | 横カルーセル | アートワーク 160×160 pt |
| お気に入りの曲 | 横カルーセル（3 段組） | 行高 64 pt、画像 44 pt、カラム幅 280 pt |
| アルバムを探す | 2 列グリッド（先頭 6 件） | 画像幅 `(表示幅 − 44) / 2` pt |

- カルーセルのカード下に作品名・アーティスト名を置く
- グリッドは左右余白 16 pt、列間 12 pt
- 「アルバムを探す」からライブラリのアルバム一覧へ誘導する
- **空セクションは省く**。全体が空なら音楽未登録の案内を出す

## 3. ミニプレイヤー

`tabViewBottomAccessory` に置き、`.tabBarMinimizeBehavior(.onScrollDown)` を併用する。

| 状態 | 内容 |
|---|---|
| `.expanded` | 画像 40 pt / 曲名・アーティストの 2 行 / 再生・一時停止 / 次曲 |
| `.inline` | 画像 28 pt / 曲名 1 行 / 再生・一時停止のみ |

- **両状態ともシークバー・時間・音量・お気に入りは出さない**
- 操作領域は最低 44×44 pt。幅不足時は曲名を省略する
- 画像・曲名の**タップ**と**上スワイプ**でフルプレイヤーを開く
- **横スワイプには操作を割り当てない**
- バッファ中は画像上に進行表示を重ねる
- 現在曲がなければ非表示。一時停止中は表示を維持する

## 4. フルプレイヤー

**`.large` 固定の sheet** で開く。上部の閉じるボタンと下ドラッグで戻す。
`fullScreenCover` と zoom transition は使わない。

安全領域内の高さ配分:

| 領域 | 比率 |
|---|---|
| 上部余白・閉じる操作 | 7% |
| アートワーク | 43% |
| タイトル・アーティスト・お気に入り行 | 12% |
| シークバーと時間 | 8% |
| 前曲・再生・次曲 | 13% |
| 音量 | 8% |
| 歌詞・出力先・キュー | 9% |

- アートワークは正方形で横幅を上限とする
- 音量は `MPVolumeView`（システム音量）を使う。エンジン側の変更は不要
- アートワークは**再生時 100% / 停止時 90%** へ拡縮。
  「視差効果を減らす」設定時は固定する
- 低い画面や文字拡大時はアートワーク領域から縮め、操作部の可読性を守る

## 5. 歌詞とキューへの導線

**下部ボタンでプレイヤー内を切り替える**（Apple Music 踏襲）。

- 「アートワーク / 歌詞 / キュー」の**排他的な 3 状態**
- 追加シートと、歌詞・キューの同時表示は採用しない
- 同じボタンの再タップでアートワークへ戻る
- **切り替えるのはアートワーク領域だけ**。曲名と再生操作の位置は固定する
- 歌詞: 現在行を強調して追従。手動スクロール中は追従を止め、「現在位置へ」で復帰。
  行タップでその時刻へシークする
- キュー: `upcoming` の順に並べ、行タップで該当位置を再生。上部にシャッフル・リピート。
  未対応の削除・並べ替えは出さない
- 歌詞なし・待機曲なしは領域内に明示する

## 6. iPad レイアウト

- **iPad も同じ 3 タブの `TabView`**。`NavigationSplitView` は採用しない
- タブバーはシステム標準の上部配置に任せる
- ミニプレイヤーは共通の `tabViewBottomAccessory`。
  下部タブバーがない場合はコンテンツ下端に配置される公式仕様に従う
- ホームのカルーセル寸法は維持。グリッドだけ 180〜220 pt を目安に列数を増やす
- フルプレイヤーは幅 560 pt を目安とする中央の大きな sheet。縦構成は維持
- 狭いウインドウでは 1 列表示へ適応。**端末名ではなく利用可能幅で判断する**
